Página de ejemplo de un cliente

Esta página simula el sitio web de un cliente donde está embebido el widget de soporte de Kasupport. Abajo a la derecha verás la burbuja de chat: haz clic, llena nombre, email, teléfono y departamento, y el chat se conectará con el equipo correspondiente dentro de la app tipo Slack.

Para embeberlo en cualquier sitio basta una línea:

<script src="http://localhost:4100/widget.js" async></script>
